# Map of mapping at MACBA

An interactive 3D map of works, exhibitions, people, publications and archive documents at MACBA (Museu d'Art Contemporani de Barcelona) connected to mapping, in English, Catalan and Spanish.

Draft by Ana Marinković, built from her research notes in Obsidian. Every record links to its MACBA source (collection, archive or library catalogue).

Open `index.html` in a browser, or view the published page via GitHub Pages.

Images: rights reserved; taken from the MACBA website or the source named on each record.
